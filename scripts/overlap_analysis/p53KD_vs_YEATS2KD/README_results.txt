p53KD versus YEATS2KD H4K16ac overlap analysis
================================================
Significant: DiffBind FDR < 0.05. Gain/loss: positive/negative Fold.
Strict overlap: unexpanded BED intervals using bedtools intersect.
BED conversion: DiffBind start was converted from 1-based to 0-based.
Lenient overlap: each peak expanded by ±1 kb or ±2 kb before intersect.
Gene assignment: closest GENCODE v50 basic gene TSS (bedtools closest).
Promoter-associated gene: nearest TSS within 2 kb.
Nearest-gene cutoff comparison: nearest TSS within 10 kb.
Exact-overlap direction counts are peak-pair counts; unique peak counts are also reported.
The peak Venn shared value is the number of connected genomic overlap components.
Intervene output is supplementary when its local installation is usable; PNG Venn plots are always generated in Python.
